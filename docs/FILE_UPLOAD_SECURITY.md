# Photos, PDFs and File Access

## Storage design

Private Supabase Storage bucket `job-photos` for approved image types; bucket `generated-reports` for server-generated PDF files. Object names are generated by backend, e.g. `orgUuid/jobUuid/randomUuid.webp`, not user-supplied. Prefix alone **does not secure files**: check active membership and job assignment before issuing grant/download, and enforce Storage policies appropriately.

## Upload sequence

1. Authenticated worker requests grant with expected size/type and job ID.
2. Backend looks up job under verified org and role; checks per-file and org quota, allowlist, safe extension and expiry.
3. Backend provides short-lived narrow upload grant to private bucket; no arbitrary object key or public access.
4. Client uploads. Backend verifies actual storage object metadata and preferably magic bytes and applies image processing/sanitisation.
5. Backend records attachment metadata in DB transaction; orphaned/unclaimed uploads expired and removed by maintenance job.
6. Access/download requires new authorised grant; expiry short enough for intended action, links not logged.

## Limits to confirm with client

Example pilot rule: JPEG, PNG, WebP only, max 10MB per photograph, maximum 12 photos per job; **proposed values**, adjust to device/network needs after testing. PDFs are generated by trusted backend, not arbitrary uploaded PDFs initially. No EXIF GPS retention unless required. Protect against ZIP bombs/malformed files and expensive image decompression.

## Acceptance tests

Cross-tenant upload and download denied; same-org unassigned technician denied; invalid type/oversize rejected; expired grant rejected; orphan cleanup; generation of signed download for valid assigned user; revocation of user blocks new grants.

## Recovery

Supabase DB backup does not automatically include object bytes. Define independent storage file backup/retention, restore integrity test and mapping to DB attachment metadata. Test recovery into **isolated** environment before production launch.
